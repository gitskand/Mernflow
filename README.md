# 📝 Task Manager – MERN Stack (Frontend + Backend)

A full-stack **Task Management Application** built using the **MERN stack** (MongoDB, Express.js, React, Node.js).  
Includes **JWT authentication**, **refresh tokens**, **dark/light theme**, and fully deployed using **Render (Backend)** and **Netlify (Frontend)**.

## 📌 Features

### 🔐 Authentication
- User Signup & Login  
- JWT Access Token + HttpOnly Refresh Token  
- Secure session flow  
- Auto-refresh on token expiry  
- Protected routes (frontend & backend)

### 📋 Task Management
- Create tasks  
- Edit tasks  
- Delete tasks  
- Mark tasks as completed  
- Responsive UI for mobile, tablet, desktop  

### 🎨 UI / UX
- React + MUI (Material UI)  
- Light / Dark mode toggle  
- Fully responsive  
- Smooth layout and card structure  

### 🛠 Backend (Node + Express)
- REST API architecture  
- MongoDB + Mongoose  
- Password hashing with bcrypt  
- Auth middleware (JWT)  
- CORS with credentials  
- Error handling & status codes  

---

## 🧩 Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | React, Vite, Material UI (MUI), Axios |
| Backend | Node.js, Express.js |
| Database | MongoDB (Atlas) |
| Auth | JWT + HttpOnly Cookies |
| Deployment | Netlify (Frontend), Render (Backend) |
